# 창업동아리 아이디어 스케치

## 아이디어 1: AI 악보(TAB) 자동 생성 앱

### 1. 주요 고객층 및 소비 패턴
- **핵심 타겟**: 밴드 동아리·실용음악 취미생, 특히 기타(일렉/통기타)·베이스·드럼 연주자 중 비전공자
- **소비 패턴 특징**
  - 유튜브 커버 영상, 스트리밍으로 원곡을 듣고 "이 곡 연주해보고 싶다"는 충동구매성 니즈가 자주 발생 → 앱 사용 트리거가 명확함
  - 정식 악보가 없는 최신곡·마이너 곡·비영어권 곡(K-pop, 인디밴드 등) 수요가 특히 큼 (공식 악보 시장이 커버 못 하는 영역)
  - 밴드 합주 준비 기간(공연/버스킹 전) 같은 특정 이벤트 앞두고 몰아서 쓰는 스파이크성 소비 가능성
  - 무료 tab 사이트(Ultimate Guitar 등)에 익숙하지만, 그 정확도·최신곡 커버리지에 불만이 있는 사용자층

### 2. 제공하고자 하는 서비스 및 Pain Point 해결
- **서비스**: 사용자가 원곡 음원을 업로드하면 AI가 악기별(베이스/기타/드럼) TAB 악보를 자동 생성
- **해결하는 Pain Point**
  - 귀카피(ear copying)에 드는 시간과 진입장벽 → 비전공자도 몇 분 안에 연주 시작 가능
  - 원하는 곡의 공식 악보가 존재하지 않는 문제 (커버리지 격차 해소)
  - 악기 파트별(기타/베이스/드럼) 분리 채보의 어려움 → 소스 분리(source separation) 기반 자동화로 해결
- **차별화 포인트**: 표준 악보가 아닌 TAB 악보로 특화 → 초보자·비전공자 접근성 극대화

### 3. 수익화 방안 및 미래 목표
- **수익화 방안**
  - 프리미엄 구독제: 무료는 월 n곡 제한, 유료는 무제한 생성 + 고음질/난이도 조절 기능
  - 크레딧(곡당 결제) 방식: 라이트 유저 대상
  - 밴드/학원 대상 B2B 라이선스 (동아리, 실용음악 학원 단체 이용권)
  - 추후 커뮤니티 기능(생성된 악보 공유·평가) → 광고 또는 마켓플레이스 수수료 모델 확장 가능
- **미래 목표 방향성**
  - 지원 악기 확장 (피아노, 보컬 멜로디 라인 등)
  - TAB → 정식 오선 악보 변환 옵션 추가로 전공자 시장까지 커버
  - 저작권 이슈 사전 검토 필요 (원곡 음원 업로드 기반이므로, 개인 학습용 명시 또는 저작권사와의 제휴 모델 검토가 향후 확장의 핵심 과제)

### 4. 구체화 — 필요 기술 스택

**파이프라인 단계별 필요 기술**

1. **음원 분리 (Source Separation)**: 원곡에서 보컬/드럼/베이스/기타를 악기별로 분리
   - Demucs(Meta, 현재 SOTA), Spleeter(Deezer) — 오픈소스로 성숙한 기술이라 자체 개발보다 기존 모델 활용/파인튜닝이 현실적

2. **음정·리듬 검출 (Automatic Music Transcription, AMT)**: 분리된 트랙에서 "언제, 어떤 음을, 얼마나 길게" 연주했는지 추출
   - 베이스/보컬 멜로디(모노포닉): 상대적으로 쉬움 — CREPE, pYIN 같은 피치 트래킹 알고리즘으로 충분
   - 기타(폴리포닉/코드): 훨씬 어려움 — 동시에 여러 음을 구분해야 함(Multi-pitch estimation). Spotify **Basic Pitch**, Google Magenta **Onsets and Frames**, **MT3** 등 참고할 기존 모델 존재
   - 드럼: 피치가 아닌 타악기 종류(킥/스네어/하이햇 등) 분류 문제 — Automatic Drum Transcription(ADT) 전용 모델 필요

3. **노트 → TAB 변환 (Fingering/Tab Mapping)**: 기타/베이스 TAB 생성만의 특수 문제
   - 같은 음이라도 지판에서 여러 프렛-스트링 조합이 가능 → 손가락 이동을 최소화하는 운지 최적화 알고리즘 필요(동적계획법 기반)
   - 코드 인식(Chord Recognition) 결합 시 화음 구간 포지션 배치가 더 자연스러워짐

4. **악보 렌더링**: 추출된 노트 데이터를 실제 TAB 악보로 시각화
   - AlphaTab, VexFlow 등 오픈소스 악보 렌더링 라이브러리 활용, Guitar Pro(.gp)/MusicXML export 고려

5. **인프라**: 소스 분리+전사 단계는 연산량이 커서 GPU 서버 필요, 업로드→처리→반환까지 비동기 큐 처리 구조 필요

**동아리 단계 현실적 접근**: 처음부터 AMT 모델을 직접 학습시키기보다, Demucs(분리) + Basic Pitch(전사) 같은 기존 오픈소스 모델을 조합해 프로토타입을 만들고, 정확도가 부족한 부분(특히 기타 코드 인식)만 자체 개선하는 방향이 현실적. 모노포닉인 베이스는 꽤 정확도가 나올 수 있지만, 폴리포닉인 기타 코드는 현재 오픈소스 기술로도 완벽하지 않다는 점은 리스크로 인지해야 함

## 아이디어 2: 듀오링고식 경제 학습 앱

### 1. 주요 고객층 및 소비 패턴
- **핵심 타겟**: 경제 공부를 시작하고 싶지만 진입장벽을 느끼는 2030 사회초년생·대학생, 재테크/주식에 관심은 많지만 기초 지식이 부족한 "투자 입문자"
- **소비 패턴 특징**
  - 듀오링고 유저들처럼 "출퇴근길, 자투리 시간에 짧게" 학습하는 습관형 소비 패턴 예상 → 스트릭(연속 학습일) 같은 게이미피케이션에 반응하는 세그먼트
  - 주식 붐/재테크 유행에 따라 관심이 급증하는 트렌드성 수요 (뉴스에 특정 이슈 터지면 유입 스파이크 가능)
  - "경제신문을 읽고 싶은데 용어를 몰라서 포기"하는 경험을 가진 사람이 많음 → 이 좌절 경험이 첫 다운로드의 트리거가 될 가능성
  - 세금·연말정산 시즌(1~2월), 신규 상장 이슈 등 특정 시기에 관련 콘텐츠 소비가 몰릴 수 있음

### 2. 제공하고자 하는 서비스 및 Pain Point 해결
- **서비스 구성**
  - 데일리 마이크로러닝: 경제 용어·개념을 짧은 퀴즈/카드 형식으로 매일 학습 (듀오링고식 스트릭·레벨업 구조)
  - 실전 뉴스 연계: 실제 경제 뉴스를 학습한 용어와 매칭해 "이 기사 이제 이해된다"는 성취감 제공
  - 세금 기초 교육 (연말정산, 소득세 등 실생활 밀접 주제)
  - 투자 기초 학습 (주식 용어, 지표 해석 등)
  - 간이 포트폴리오 진단: 사용자가 보유 종목/자산 비중 입력 시 리스크·분산도 등을 간단히 평가해주는 기능
- **해결하는 Pain Point**
  - "경제 공부는 어디서부터 시작해야 할지 모르겠다"는 막막함 → 커리큘럼화된 단계별 학습으로 해결
  - 경제신문을 봐도 용어 때문에 이해가 안 되는 문제 → 뉴스와 학습 콘텐츠를 직접 연결해 실질적 독해력 향상
  - 투자는 하고 있지만 자신의 포트폴리오가 괜찮은지 판단할 기준이 없는 문제 → 진단 툴로 최소한의 가이드 제공

### 3. 수익화 방안 및 미래 목표
- **핵심 비전(미션)**: 사람들이 스스로 자신의 자산을 관리하고, 어느 정도 시장 흐름을 스스로 파악할 수 있는 능력을 갖추게 하는 것 — "정보를 대신 떠먹여주는" 앱이 아니라 "스스로 판단하는 법"을 가르치는 앱
- **수익화 방안**
  - 프리미엄 구독: 무료는 기초 커리큘럼, 유료는 심화 콘텐츠(세금 절세 전략, 고급 투자 지표 등) + 광고 제거
  - 금융사 제휴/리퍼럴: 증권사·은행 계좌 개설 연계 수수료 (단, 정보 신뢰성과 이해관계 충돌 관리가 필요 — 자문처럼 보이지 않도록 "교육 목적" 선을 명확히 해야 함)
  - B2B: 기업 신입사원 대상 금융 리터러시 교육 콘텐츠 라이선싱
- **미래 목표 방향성**
  - 포트폴리오 진단 기능을 점진적으로 고도화 (단, 투자자문업 라이선스 이슈가 걸릴 수 있어 "정보 제공"과 "자문" 사이 법적 경계를 초기에 명확히 정의할 필요)
  - 사용자 학습 데이터 기반 맞춤형 콘텐츠 추천으로 확장
  - 세금·투자 외에 부동산, 연금 등 자산관리 전 영역으로 커리큘럼 확장

### 4. 구체화 — 차별화 전략 (경쟁사 대비)

**경쟁 구도**

| 유형 | 예시 | 강점 | 약점(우리 기회) |
|---|---|---|---|
| 뉴스레터형 | 뉴닉, 어피티 | 낮은 진입장벽, 큰 구독자층 | 읽기만 하는 수동적 소비, 게이미피케이션·습관 형성 장치 없음 |
| 습관형 챌린지 | 어피티 "머니 트레이닝 클럽" | 실제 행동 변화 유도, 커뮤니티 요소 | 기수제/유료 프로그램이라 진입장벽 있음, 매일 쓰는 앱이 아님 |
| 증권사 인앱 교육 | 토스증권, 삼성증권 mPOP 등 | 실거래 연동, 신뢰도 | 교육이 부속 기능, 학습 경험이 얕고 커리큘럼화 안 됨 |
| 해외 유사 모델 | Zogo(미국) | 듀오링고식 게이미피케이션+은행 제휴 B2B2C | 국내 미진출, 한국 세금·시장 특화 아님 |

**차별화 포인트**
1. **게이미피케이션의 깊이**: 스트릭·레벨·리그(랭킹 경쟁) 등 듀오링고 특유의 습관 형성 메커니즘은 경쟁사 어디도 제대로 갖추지 못함 → 가장 확실한 차별화 축
2. **학습-뉴스 실시간 연결**: 어피티/뉴닉은 "읽기"만 제공하지만, 오늘 배운 용어가 실제 등장한 최신 기사를 큐레이션해 즉각적 피드백 루프 제공
3. **통합 커리큘럼**: 경제기초·세금·투자가 파편화된 시장에서, 하나의 앱·하나의 성장 경로(스킬트리)로 묶는 곳이 없음
4. **초보자 전용 포트폴리오 진단**: 증권사 리포트는 전문가용이라 딱딱함 → 초보자가 이해할 수 있는 쉬운 언어의 진단 제공

### 5. 구체화 — 핵심 기능 및 커리큘럼 설계

**커리큘럼 구조 (스킬트리 방식)**

Track 1. 경제 기초 (신문 읽기 능력)
- Unit 1: 물가·금리·환율 기초 용어
- Unit 2: GDP·경기순환 이해
- Unit 3: 통화정책·재정정책 (한국은행 기준금리 등)

Track 2. 세금 (실생활 밀접)
- Unit 1: 근로소득세·연말정산 기초
- Unit 2: 종합소득세·사업/기타소득
- Unit 3: 자산 관련 세금 (양도소득세, 종합부동산세, 금융투자소득세)

Track 3. 투자 기초
- Unit 1: 주식 용어 (PER, PBR, ROE, 배당수익률 등)
- Unit 2: 채권·펀드·ETF 기초
- Unit 3: 리스크 관리·분산투자 개념

→ Track은 병렬 진행 가능하되, 각 Unit은 순차적 잠금 해제 (듀오링고 방식)

**핵심 기능**
1. 데일리 레슨: 객관식·빈칸채우기·매칭 등 짧은 문제 형식, 5분 내외
2. 스트릭 & 리그: 연속 학습일 기록, 주간 랭킹으로 소셜 경쟁 유도
3. 뉴스 매칭 리더: 학습한 용어가 포함된 실제 최신 기사 자동 추천 + 기사 내 용어 하이라이트
4. 간이 포트폴리오 진단: 보유 종목/비중 입력 → 섹터 집중도, 변동성 수준, 분산 점수를 시각화 (투자자문이 아닌 "교육적 피드백"으로 법적 포지셔닝)
5. 세금 캘린더 알림: 연말정산, 종소세 신고 시즌 등에 맞춘 시의성 콘텐츠 푸시

### 6. 구체화 — 미션이 설계에 미치는 영향
- **철학**: "물고기를 잡아주기"가 아니라 "낚시하는 법을 가르치기" → 매수/매도 추천 같은 기능은 지양, 스스로 판단할 수 있는 프레임워크(지표 읽는 법, 리스크 평가 기준)를 가르치는 데 집중
- **성공 지표(KPI) 재정의**: 단순 DAU·구독 유지율뿐 아니라 커리큘럼 완주율, 레벨업 지표 등 "사용자가 스스로 판단할 수 있게 됐는가"를 측정하는 지표가 중요
- **포트폴리오 진단 기능의 역할**: 단순 결과 제시가 아니라 "왜 이런 평가가 나왔는지" 설명하는 교육적 피드백으로 설계 (미션 부합 + 자문업 규제 회피에도 유리)
- **리텐션 전략의 역설과 대응**: 목표를 달성한 유저(자산관리 자립)는 이탈 가능성 있음 → 이를 "졸업"으로 긍정적으로 포지셔닝하고, 심화 트랙(고급 투자, 부동산, 은퇴설계 등)으로 계속 성장 경로를 열어 리텐션 확보

### 7. 확장 아이디어 — 경제 팟캐스트 연계 기능
- **아이디어 출발점**: 이동 중(출퇴근길 등)에 경제 팟캐스트를 들으면서 내용을 이해하고 싶다는 개인적 니즈에서 착안
- **기능 방향**: 경제 팟캐스트와 제휴하여 앱 내에서 청취 가능하게 하고, 그날 방송 내용의 요약본을 함께 제공
- **확장 시 고려할 점**: 요약 제공에서 그치지 않고 방송 내용 기반 간단 퀴즈로 연결하면, 기존 학습 루프(뉴스 매칭 리더)와 자연스럽게 통합되어 "듣기만 하고 끝"이 아닌 이해도 검증까지 가능
- **실행 시 유의점**
  - 팟캐스트 제작자와의 라이선싱/수익 분배 협상 필요 (자체 콘텐츠 제작보다 리소스는 절약되나 협상이라는 변수 발생)
  - "가르치는 앱"이라는 핵심 미션이 흐려지지 않도록, 요약·퀴즈 등 학습 루프 안에 묶어서 설계
- **포지셔닝**: 초기 MVP 범위보다는 파트너십 기반의 2단계 확장 기능으로 우선순위 설정

## 두 아이디어 경쟁력 비교

**결론: 실행 경쟁력은 경제 학습 앱 쪽이 더 높음**

- **핵심 이유(기술 난이도)**: TAB 악보 앱은 오디오 소스 분리 + 채보라는 고난도 AI 기술이 필요한데, 이미 Moises, Songsterr, Ultimate Guitar 같은 강력한 경쟁자가 유사 기능을 갖추고 있어 학생 동아리 수준에서 차별화된 기술 완성도를 내기 어려움
- 반면 경제 학습 앱은 콘텐츠·UX 중심이라 MVP를 훨씬 빠르게 검증할 수 있고, 시장(재테크 관심층) 규모도 훨씬 큼

**트레이드오프**
- TAB 악보 앱: 성공 시 니치하지만 충성도 높은 유저층과 진짜 기술 해자(moat) 확보 가능
- 경제 학습 앱: 진입장벽이 낮은 만큼 콘텐츠 차별화(뉴닉/어피티, 토스 등과의 경쟁)가 관건

**추천**
- 동아리 단계에서 빠르게 프로토타입을 돌려보고 싶다면 → 경제 학습 앱
- 기술 자체를 도전 과제로 삼고 싶다면 → TAB 악보 앱
